# Icaros

Frontend mobile-first de um produto de link-in-bio, construído com Vite,
React, TypeScript, TanStack Router/Query e Tailwind v4. O backend é
simulado por MSW para permitir navegar pelo produto localmente.

## Preferências do projeto

- Interface e mensagens em português do Brasil.
- Manter a arquitetura e o stack existentes; evitar migrações grandes.
- Usar componentes visuais reutilizáveis para a identidade Icaros.
- A autenticação Google permanece mockada até que um Client ID e um backend
  real sejam configurados.
